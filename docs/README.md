# HUZZAH32 Project Documentation

This directory documents the Adafruit HUZZAH32 port of B.B. Link.

## Documents

- [HUZZAH32 Port](HUZZAH32_PORT.md) — architecture, software changes, compatibility and scope.
- [Build Guide](BUILD_GUIDE.md) — Arduino setup, dependencies, compilation and flashing.
- [TH-D75 Setup](TH-D75_SETUP.md) — Kenwood radio-side setup and troubleshooting.
- [RadioMail Setup](RADIOMAIL_SETUP.md) — iPhone/iPad connection and session workflow.
- [Test Plan](TEST_PLAN.md) — incremental functional and reliability validation.
- [Project Status](PROJECT_STATUS.md) — completed work, current testing and publication boundaries.

## Hardware

Mechanical hardware documentation is deliberately withheld while the enclosure remains under development. CAD, STL, dimensions, battery packaging and mechanical BOM information should not be added until the design is approved.
